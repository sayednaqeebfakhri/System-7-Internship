# Day 15 – Model Evaluation

## Overview
Studied model evaluation techniques for classification and regression problems using Python and Scikit-learn.

## Topics Covered
- Train-Test Split
- Cross-Validation
- Accuracy, Precision, Recall, and F1-score
- Confusion Matrix Visualization
- ROC Curve and AUC
- Regression Metrics: MAE, MSE, RMSE, and R²
- Five-Fold Cross-Validation
- ROC Curve Comparison: Logistic Regression vs Random Forest

## Tools and Libraries
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Practical Exercises
1. Implemented train-test splitting on the Iris dataset.
2. Evaluated classification performance using different metrics.
3. Visualized a confusion matrix.
4. Calculated ROC curves and AUC scores.
5. Implemented regression evaluation metrics and verified them using Scikit-learn.
6. Compared Logistic Regression, KNN, and Random Forest using five-fold cross-validation.
7. Compared Logistic Regression and Random Forest using ROC curves.

## Key Learning
Learned how to evaluate machine learning models, measure prediction errors, analyze classification performance, and compare different models using appropriate evaluation techniques.
