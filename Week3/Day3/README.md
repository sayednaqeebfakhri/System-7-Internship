# SVM and Clustering

## Overview
This repository contains practical implementations of advanced machine learning algorithms, including Support Vector Machines, Naive Bayes, and clustering techniques.

## Topics Covered

### 1. Support Vector Machines (SVM)
- Introduction to SVM
- Support vectors and margins
- Linear, RBF, Polynomial, and Sigmoid kernels
- Multiclass classification using One-vs-One

### 2. Naive Bayes
- Bayes' Theorem
- Conditional probability
- Gaussian Naive Bayes
- Classification using Iris dataset

### 3. K-Means Clustering
- Introduction to unsupervised learning
- Centroids and cluster assignments
- Feature scaling
- Elbow Method
- Silhouette Score

### 4. Hierarchical Clustering
- Agglomerative clustering
- Ward linkage
- Dendrograms

### 5. DBSCAN
- Density-based clustering
- Epsilon (`eps`)
- Minimum samples (`min_samples`)
- Core, border, and noise points

### 6. Model Comparison
Compared SVM and Gaussian Naive Bayes using the Breast Cancer dataset.

Evaluation metrics:
- Accuracy
- Precision
- Recall

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Datasets
- Iris Dataset
- Breast Cancer Dataset

## Learning Outcome
Developed practical understanding of supervised classification algorithms and unsupervised clustering techniques, along with model evaluation and cluster selection methods.
